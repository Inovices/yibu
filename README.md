# 一步

每天只推进一步。打开就能学，不用自己排计划。

## 这是什么

一个极简的每日学习推进器，理念是「降低启动门槛」——每天只给你一小步，按你当下的精力自动调整深浅。

## 技术

- 纯前端单页（HTML + CSS + 原生 JS），无构建步骤
- 支持 PWA：可「添加到主屏」作为独立应用使用，支持离线访问
  - `manifest.json`：应用元信息与图标
  - `sw.js`：Service Worker，缓存页面与图标
  - `icon-192.png` / `icon-512.png`：占位图标（后续可替换正式 logo）

## 本地运行

直接用静态服务器打开即可（PWA 需 http/https，不能 file://）：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080/`。
